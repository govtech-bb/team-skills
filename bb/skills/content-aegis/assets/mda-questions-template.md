# Questions for the MDA or service owner

Use only the sections and questions needed for the current service.

Do not send this as a compulsory full questionnaire.

Before treating questions as final for external use, give the operator or content designer the proposed questions to review. A user’s request to draft questions is enough to prepare them; do not ask again before drafting. Sending remains a separate authorised action.

Keep the following assessment internal unless a traceability record is requested. In an ordinary user-facing question draft, show the question and only the short reason needed to answer it.

For each proposed question, record enough context to judge it:

- Question: [specific question]
- Trigger/source location: [where the uncertainty comes from]
- Why this matters: [what content, route or rule the answer affects]
- Proposed owner: [MDA/service owner or other owner]
- Blocks current work: [Yes/No]
- Interim treatment: [what can safely continue]
- Status: [Proposed / Approved to ask / Rejected / Redirected / Resolved / Unresolved]

`Approved to ask` means the operator agrees the question should be sent. It does not approve the answer or any resulting service change.

## Instructions

- Check whether current evidence already answers the question before escalating it.
- Check that the MDA or service owner actually owns the decision.
- Ask only questions whose answers materially affect content, route, requirements, eligibility, cost, deadline or next steps.
- Ask no more than 3 questions at one time in conversation, prioritising blockers; a requested complete document may list the remaining questions.
- Continue unaffected work where safe.
- Use the terms the MDA already uses where they are clear.
- Ask for facts and operational rules.
- Do not ask the MDA to select page patterns, headings or GovTech content style.
- Remove empty sections.
- Do not manufacture questions when none are needed. Zero questions is a valid outcome.
- Order retained questions by material impact; combine genuinely related information-purpose questions where helpful without hiding separate decisions.
